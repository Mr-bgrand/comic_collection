# Singularity soundtrack

`cornfield-chase.mp3` is the owner's supplied **Cornfield Chase**, by Hans Zimmer,
from the *Interstellar* soundtrack (WaterTower). The MP3 is preserved as supplied;
the duplicate MP4 is not needed by the app.

The builder copies this file to `dist/review/audio/`. Singularity loads it on
demand, loops it, and follows the scene's play/pause state. Hide controls only
hides the interface. The Music button remembers an explicit off preference.

Music pauses when leaving Singularity or backgrounding the page. A browser that
blocks the first playback attempt shows **Music play**; a tap starts playback.
Playback resumes from the same position. Music is an optional presentation layer,
not part of collectible scans or certification evidence.
