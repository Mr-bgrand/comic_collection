# Drop cover photos here

Name them by CGC cert number:

    4245413012_front.jpg
    4245413012_back.jpg

Then run `npm run images:import`. Files move to `imported/` once processed.

CGC has no scans for 21 books in this collection -- imaging is an add-on those
submissions did not include, so waiting will not produce them. A photo of the
slab is the only way to get the real thing.
