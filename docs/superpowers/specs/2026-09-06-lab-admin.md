# Collection / Lab Admin

The owner requested an Admin/settings surface for case labels, master sheets and
bin names, confirming the existing 4 × 6 and 8.5 × 11 formats and the usual
`npm run build` followed by `npm run print` workflow.

## Implemented

- Gear / Admin opens a responsive control-room dialog with Bins & locations,
  Print Studio, Collection backup and Photos. The object scene remains the main interface.
- Bin name and location edits update `data/bins` through a loopback-only server.
  Bin IDs, copy records and QR destinations remain stable. Saves use file revisions
  to reject stale writes, atomic replacement, and a local prior-record backup.
- Print Studio uses the existing label/sheet templates. Live previews have Print /
  Save PDF controls. Custom bin names appear on labels, sheets and catalogue pages.
- Build & generate runs the existing `npm run build` and `npm run print` commands,
  in order, without dispatching a physical print job. Build-only and print-only
  actions are also available, with progress, bounded logs and resulting PDF links.
- `npm run build` now runs the existing catalogue generator followed by the Lab
  builder, so rebuilding no longer removes the current interactive review.
- Collection master list includes comics, PSA cards and raw Authority records;
  missing values remain unknown and estimate dates stay distinct from export dates.
- JSON backup includes the complete stored record data and scan references. Image
  files remain in the collection directory. Automatic bin backups are gitignored.
- Photos finds existing comics, cards and Authority copies by cert or title. The
  owner chooses a side, previews a camera/library image, rotates and explicitly
  saves it. An optional QR link opens a focused phone intake on the same Wi-Fi;
  the phone can search the next cert without returning to the computer.
- Image replacement keeps the previous file and provenance in `imageHistory`,
  backs up the record, validates its revision, and writes new image derivatives.
  Orientation is corrected and embedded metadata removed. A successful save
  rebuilds the interactive review; the UI links to refresh the desktop collection.

## Run

`npm run build`, then `npm run lab`, then open http://localhost:4175/review/.
`npm run print` remains available unchanged. The server binds only to 127.0.0.1;
local Admin is intended for this computer. Hosted/portable previews show read-only
controls, and do not imply that edits have been saved. Serving with a generic
static server does not provide the management API. Phone pairing starts a separate
photo-only listener on port 4176. Its random pairing token expires after 30 minutes
and can be revoked from Admin. The main Admin API stays on loopback. Keep the
computer running and both devices on the same private network while taking photos.

The generated bin PDFs live in `print/`, with all existing filenames preserved.
No commit, deployment or printer dispatch is performed by Admin. Additional
collection import/edit/move flows, full mobile administration and cloud account
management are separate work. Photo intake only updates existing exact-copy
records; it does not import a new cert.

## Verification

The build-and-print button completed against the current inventory and produced
22 PDFs: eleven one-page 4 × 6 labels, ten two-page Letter sheets and one one-page
Letter sheet for Display Wall. Representative label/sheet PDFs were rendered and
visually checked. Automated checks cover persistence, retained copy data, backups,
stale edits, escaped custom names, source isolation and the local print endpoints.
Browser checks cover connected desktop/mobile Admin, dirty/save state, section
navigation, live inventory counts, print progress and all 22 result links.

Photo checks cover exact-copy selection across graders, front/back replacement,
orientation, metadata removal, prior-image retention, idempotency, stale revisions,
invalid images, bounded uploads, phone pairing, revocation, expiry, origin checks,
and the awaited review rebuild. Browser testing used a separate fixture collection
for camera-picker upload, preview, rotation and both saves. The live collection's
QR link was opened through its Wi-Fi address and the 390 × 844 phone layout checked;
physical phone hardware capture remains a device check.
